Infraestructura de Registro de Evento Country Dance — Estabilidad Operativa

Contexto

Entorno operativo de registro que soporta un evento público de country dance, gestionando participantes, inscripciones de grupo y workflows administrativos mediante un modelo de dominio ejecutable derivado del mismo execution meta-model.

  • Inscripciones de grupo para equipos de baile
  • Registro individual de participantes
  • Validación estructurada de datos
  • Workflows de revisión administrativa
  • Gestión operativa de inscripciones durante la temporada del evento

Lista operativa de inscripciones con participantes y grupos provenientes de varios países europeos.

Métricas operativas

Operativo desde 2022 (5º ciclo del evento)
Operación estacional Marzo – Mayo cada año
Participantes de Varios países europeos
Pico de actividad Durante los días de apertura

Crecimiento de inscripciones a lo largo de las ediciones:

2022 250 inscripciones
2023 540 inscripciones
2024 650 inscripciones
2025 780 inscripciones

Formulario de registro generado a partir del modelo de dominio ejecutable.

Fiabilidad operativa

El sistema ha sido utilizado a lo largo de múltiples ciclos anuales del evento, soportando picos de registro durante el periodo de apertura y un uso continuo durante la temporada.

  • Sin fallos estructurales en la lógica de la aplicación
  • Raros eventos de downtime relacionados con la infraestructura
  • Integridad de datos consistente entre diferentes ediciones
  • Operación estable sin necesidad de regeneración del modelo

Evidencia generativa

Comparación cuantitativa entre la definición DSL y el sistema runtime generado.

Líneas del modelo DSL 593
Líneas de código generadas (runtime) 36,461
Ratio de compresión (DSL → runtime) 1 : 61

El sistema se genera a partir del modelo DSL, que instancia el execution meta-model, con extensiones manuales limitadas para personalización de UI y ajustes operativos.

Significado arquitectónico

Este sistema demuestra:

  • Estabilidad operativa a lo largo de múltiples ciclos
  • Escalabilidad con volúmenes de registro crecientes
  • Fiabilidad en condiciones reales de uso estacional
  • Portabilidad cross-platform del sistema generado
  • Migración de Windows a Linux sin cambios en la aplicación

Punto clave

No desplegado una sola vez y reemplazado — sino operado continuamente a lo largo de múltiples ciclos con participación creciente.
