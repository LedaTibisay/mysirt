Evaluation Access

MySirt can be evaluated through a controlled demonstration environment. The objective is not to showcase interface aesthetics, but to examine structural generation, model interpretation, and execution coherence.

The evaluation focuses on the engine’s deterministic behavior and its ability to derive operational systems from formal definitions.

Evaluation Scope

  • Inspection of a generated multi-entity system
  • Navigation of structured forms and derived views
  • Workflow-driven state transitions
  • Rule-based enforcement and responsibility modeling
  • Observation of model-to-system derivation principles

Evaluation Environment

The MySirt evaluation environment is available at mysirtapp.com.

Registration is the first step of the evaluation process. After registering, users do not yet have access to the evaluation workspace. Each request is reviewed by the MySirt team to ensure that evaluations take place in an appropriate technical context.

Only after approval is the evaluation workspace activated. Once activated, evaluators can access the available technical documentation and two fully functional demonstration systems generated with MySirt.

The evaluation environment is designed to allow professional assessment of the Model Execution Engine while protecting proprietary technology and intellectual property.

Open Evaluation Portal

Generation Visibility

The evaluation environment illustrates how structured definitions are interpreted and transformed by the Model Execution Engine into executable information systems.

Where appropriate, regeneration behavior shows how the generated system remains structurally consistent with the model.

Access Policy

The registration portal is public, but the evaluation workspace is not a public sandbox. Workspace activation requires approval by the MySirt team.

Access is intentionally controlled to ensure meaningful technical evaluations while protecting proprietary technology and intellectual property.

Intended Audience

  • Software Architects
  • Technical Decision Makers
  • Engineering Teams evaluating Model-Driven technologies
  • Organizations exploring integration, licensing or acquisition

Intellectual Property

The demonstration environment shows the operation of the Model Execution Engine and generated systems without exposing the complete DSL or other proprietary assets.

The public documentation presents the architectural principles and execution model. Detailed documentation is shared only during structured technical evaluations and, where appropriate, within confidentiality agreements.
