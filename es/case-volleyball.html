Sistema de Gestión para Club de Voleibol — Generatividad Progresiva

Contexto

Sistema de gestión para un club de voleibol que soporta operaciones administrativas, seguimiento de atletas y gestión financiera. El sistema fue desarrollado y mantenido progresivamente por un responsable deportivo sin experiencia previa en programación, demostrando cómo los expertos de dominio pueden convertirse progresivamente en modeladores de sistemas utilizando la DSL de MySirt.

  • Gestión de atletas y equipos
  • Entrenadores y personal
  • Seguimiento de certificados médicos
  • Generación de recibos fiscales
  • Workflows administrativos

Progresión de aprendizaje

El sistema fue inicialmente configurado utilizando herramientas de modelado visual. Tras un breve periodo de incorporación, el experto de dominio pasó progresivamente a la edición directa de la DSL, llegando a mantener de forma autónoma el sistema de información.

Fase inicial

Configuración visual mediante formularios y constructores de entidades MySirt.

Fase intermedia

Edición asistida de la DSL para reglas de negocio y ajustes estructurales.

Fase autónoma

Mantenimiento independiente del sistema mediante DSL.

Interfaz de búsqueda generada automáticamente a partir del modelo de dominio con parámetros de filtrado específicos.

El sistema de información fue generado completamente a partir de la definición DSL, que instancia el execution meta-model. El experto de dominio mantuvo el sistema actuando directamente sobre el modelo, sin modificar el código runtime generado.

Esto demuestra la transición progresiva de un experto de dominio desde la configuración hacia la modelización completa del sistema mediante DSL.
